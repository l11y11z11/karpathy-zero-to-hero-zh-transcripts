# 卡帕西Neural Networks: Zero to Hero的文字稿中文版

Andrej Karpathy《Neural Networks: Zero to Hero》课程的中文学习版文字稿。

本仓库收录 8 讲中文整理稿，适合在观看原视频时对照阅读。整理过程中保留了课程中的代码、公式、张量形状分析和调试思路，并对自动语音识别文字稿进行了断句、口语冗余和 Markdown 结构整理。

> 本项目是非官方中文翻译与学习整理，与 Andrej Karpathy 或 OpenAI 无隶属关系。原课程、视频和相关代码的权利归原作者及相关权利人所有。
